AntiSlop.

Deterministic rules and liveliness filters for AI coding assistants. Stops coding agents from generating generic "AI slop" UI and robotic copy, without letting the result turn sterile.

GitHub Open Source on GitHub skills.sh Listing Article Read Technical Article

Overview & Philosophy

AntiSlop is a filter, not a style guide: it does not prescribe colors, fonts, or rigid layouts. Instead, it systematically strips away the mathematical average of the Internet that LLMs gravitate toward (purple gradients, rounded pill badges, low contrast text, and robotic corporate copy). It is not only for building pages: it also writes and audits copy, so AI text stops reading like AI.

The core prevents slop but cannot invent creative direction. Your project's DESIGN.md supplies the aesthetic soul; a sterile result means the direction was missing, not that the filter failed.

Core Architecture & Tiers

The engine enforces 38 mandatory rules (R-01 to R-38) organized into three strict operational tiers, complemented by a Liveliness Toolkit:

  • Hard Gate: Absolute prohibitions (no generic purple gradients, no em dashes, no robotic markdown tags, no unstyled bento grids).
  • Purpose-Gate: Techniques allowed only when explicit functional rationale is provided.
  • Quality Locks: Strict cross-file consistency for typography, border contrast, and interactive feedback.
  • Liveliness Toolkit: Three active dials (ENERGY, RHYTHM, MOTION) and a Design Read to keep output specific, alive, and human.
  • Delivery Gate: Mandatory PASS or FAIL verification report executed before any code ships.

How to Install & Run

antislop is built upon the open Agent Skills standard and natively supports 7 assistants: Claude Code, Antigravity CLI, Codex, OpenCode, Cursor, Gemini CLI, and Hermes. Choose from 5 official installation paths:

1. Interactive CLI Picker (Recommended)
$npx antislop-ai
2. Antigravity CLI Plugin
$agy plugin install https://github.com/miqdadbadjuber/anti-slop
3. Codex CLI Plugin & Marketplace
$codex plugin marketplace add miqdadbadjuber/anti-slop
$codex plugin add antislop@anti-slop
4. Claude Code Native Plugin
/plugin marketplace add https://github.com/miqdadbadjuber/anti-slop
/plugin install antislop@anti-slop
5. skills.sh Open Registry
$npx skills add miqdadbadjuber/anti-slop
6. Single-File Direct Fetch
$curl -o antislop.md https://raw.githubusercontent.com/miqdadbadjuber/anti-slop/main/antislop.md

Operational Modes

antislop operates in two dedicated modes chosen at the start of any session:

$ antislop --mode=during
[active-watch] Intercepting AI token stream in real time...
1. No generic purple gradients PASS
2. Contrast ratio ≥ 4.5:1 PASS
3. No robotic tags or badge slop PASS
Delivery Gate: PASSED. All 38 rules verified.
