# Miqdad Badjuber - Portfolio

Personal portfolio website featuring an interactive 3D background, smooth animations, and a modern dark aesthetic.

## Features
- **3D Quantum Core Background**: Interactive WebGL scene built with Three.js.
- **Mobile-First Carousel**: Smooth, infinite-looping project showcase.
- **Fluid Animations**: Scroll-triggered reveals powered by GSAP & Lenis.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Tailwind CSS (Styling)
- Three.js (3D Rendering)
- GSAP (Animations)
